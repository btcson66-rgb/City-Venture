## 主軸

從 $30,000 開始，親手把一門網路小生意從零做起來：

1. 進貨
2. 拍照上架
3. 接單、打包
4. 寄出、收錢

等貨時去打工。

## 第一次創業引導（18 步）

教學卡會說明現在要做什麼。金色箭頭指向要去的地方。

視窗打開時會蓋住教學卡。這時要按的按鈕會有金色閃框，旁邊的提示泡泡寫出兩件事：

- 現在是第幾步，例如「第一次創業 9/18 · 第一次進貨」；
- 這顆按鈕要做什麼，例如「買手機架」。
