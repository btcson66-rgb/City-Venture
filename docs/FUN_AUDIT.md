# 遊戲樂趣與行政負擔稽核（#154）

玩家是來玩的，不是來上班的。本文件先於任何 #154 程式變更提交。步驟數以畫面內必需操作計，旅行另列；屬來源稽核，未實測的流程不能當成 walkthrough 通過。#153/#151 已移除回覆與未解鎖入口，本輪保留經營方向、定價、投資、人際與故事判斷，把固定行政交給助理。R4、雙式帳務、舊存檔與 no soft-lock 不變。

## 助理的界線

每一種雜事提供可保存的開關，新手預設開；畫面與設定總覽可切回手動。助理只操作已擁有的資產和已作成的營運決定，不新借款、不簽募資、不任意購置產業、不製造銷售。現金不足時停止可選採購，顯示一次可恢復的通知，不免費補款。合理營運／充足周轉金的 90 天測試與一般資金不足測試分開，不能宣稱任何公司必然不破產。

## 主線節奏與验收

逐章先看「現在」要做的一個決定，其餘 administrative 目標由真實自動處理的 stat/receipt 完成；不能靠假旗標跳章。首三章保留出門、咖啡、選事業、第一個客人、正式註冊與工作空間；將逐單包裝出貨變成可選手動遊戲。完整 1–24 章須由新遊戲、不靠手機回覆、全部助理開啟走通，步驟數另從實際 walkthrough log 計算。

本文件的步驟表是來源盤點／目標，執行成果、90 天與完整渲染 walkthrough 尚待驗證。使用者要求 Draft PR，故先推送稽核提交供審閱，不在本 session 合併。
