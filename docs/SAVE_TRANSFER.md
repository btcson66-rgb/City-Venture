# 存檔攜帶與復原

暫停選單、讀檔清單皆提供「匯出存檔」與「匯入存檔」。匯出使用完整 slot 格式，包含玩家位置、帳本、故事、排程及隨機數狀態；檔名為 `CityVenture_<玩家名>_<遊戲日期>.cvsave`。檔名中的作業系統保留字元會換成底線。

桌面版使用檔案選擇視窗；網頁版下載檔案，匯入時選擇 `.cvsave` 或 `.json`。瀏覽器資料清除、換瀏覽器或換電腦前，先匯出並另外保管檔案。

匯入會先驗證格式、版本、資料結構及帳本，再補齊舊版本缺少的欄位。預設使用空槽；六個槽皆占用時，必須自行選擇並確認取代。原檔會先複製至 `saves/replaced/`，任何驗證、備份或寫入失敗都保留原有主檔及目前遊戲。

每個槽另外保留 `slot_n.bak1`、`.bak2`、`.bak3` 三份最近備份。主檔損壞時，讀檔清單提供「使用上一份備份」，優先使用最近一份通過驗證的備份，並保留損壞原檔供調查。

開發者：存檔寫入先完成暫存檔，再以檔案系統 rename 取代主檔；不使用先刪除再寫入。瀏覽器 FileReader callback 在讀檔期間保持引用，完成或取消後延後釋放。歷史存檔來源與回歸規則見 `game/tests/fixtures/saves/README.md`。
