# 人生回顧與新人生＋（Implemented，#92）

手機「人生紀錄」可依公司、人生、人脈、危機與里程碑，以及實際日曆年份篩選。章節與決策紀錄可以保留現有美術的路徑，素材存在才顯示縮圖；員工事件另標記為人脈。舊存檔保留原始時間與文字，未記錄的事件不會憑空補寫。

`data/legacy.json` 有七種類型：`builder` 建造者、`merchant` 商旅、`innovator` 創新者、`operator` 實幹者、`local_legend` 在地傳奇、`comeback` 東山再起者、`quiet_owner` 從容的經營者。公式在每個類型的 `formula`：各來源除以指定分母、限制在 0 至 cap，再乘權重相加。來源為實際營收產業、員工、交付、軟體功能、能源安裝、充電站、城市開發、人脈、公司關閉後重新有營收、帳面淨值與工作紀錄；同分按 ID 排序，主要與次要類型都保留。

主線尾聲讀完即能開啟人生回顧，也可在暫停選單選擇退休。退休門檻為生活三十天或完成主線，不替玩家關閉或出售公司。快照包含評分、最多五個關鍵時刻、統計、角色與類型組合尾聲；依資料中的事件權重與時間排序，重讀不改寫舊紀錄。舊存檔缺少工時的部分明列不完整，新版記錄實際班次、咖啡店與開發分鐘，以及已有的接案小時；開發效率加成不等於實際工時。負淨值照實呈現，不用零遮蔽。

新人生＋需要先選「下一代」或「同一角色的新人生」，再確認。先保存原局，僅使用空白槽，槽已滿時可以繼續原局，沒有暗中覆寫。保留角色外觀與上一局快照，舊公司、營收、成就與工作紀錄不搬入新局。繼承資本依主要類型不同，最多為當下帳面淨值的 5%，且不超過 2,500 本國元；淨值不正則沒有繼承款。帳目借記現金、貸記資本，不是營收。在地傳奇另保留 Maya 的人脈。

難度每局提高一級，起始資金乘以 80% 的難度次方，零售需求乘以 90% 的難度次方、最低 30%；一般新遊戲完全沿用既有數值。新人生章節卡與時間軸呈現實際起始資金，不再誤寫 30,000。所有主要按鈕固定在捲動區外，回顧不會把玩家困住。

短測 `--from=life_legacy` 以三種不同的受控操作路線產生獨立存檔：20 筆海外實際訂單的打包、快遞與交付；實際開發 MVP 與八項功能；實際關閉與重新登記公司後完成第一筆交付。分類分別為商旅、創新、東山再起。這是受控模組流程，不宣稱為三份無介入的長期經濟策略模擬。專屬傳承類型插圖為 Planned，介面使用既有素材。
