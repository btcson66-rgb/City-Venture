# CITY VENTURE 遊戲 Wiki

這份 wiki 是遊戲世界的**設定集與美術規格書**，寫給兩種人：

- **製作人 / 企劃**：Aurelia 這座城有什麼地方、有哪些人、玩家能用什麼東西，哪些已經做好、哪些還在規劃。
- **美術（Codex 或像素畫師）**：每一張圖的檔名、尺寸、用途、目前品質和優先順序。依照這裡的規格交圖，不用改程式就能進遊戲。

遊戲本體的程式、數值和劇情由 Claude Code 這條線負責，畫面由美術線負責。兩邊的接點是**檔案路徑和尺寸**。這份 wiki 就是雙方的合約。

## 狀態標記

每個條目都有兩種狀態：玩法狀態和美術狀態。

**玩法狀態**（沿用專案的誠實用語）

| 標記 | 意思 |
|------|------|
| 已實作 Implemented | 遊戲裡玩得到 |
| 模擬 Mocked | 有畫面，但背後是簡化的假資料 |
| 規劃中 Planned | 設定已定，程式和美術都還沒做 |
| 受阻 Blocked | 等外部條件（例如 iOS 需要 Mac） |

**美術狀態**

| 標記 | 意思 |
|------|------|
| `CODEX` | Codex 2026-09-28 美術修整版，目前最新 |
| `CONV` | 從概念板（`docs/reference/concept_boards/`）自動轉換，網格和調色盤正確，但不是手繪定稿 |
| `GEN` | 程式產生的佔位圖（`tools/art/*.py`） |
| `重繪` | 已有檔案，要換成定稿 |
| `新增` | 還沒有檔案 |
| `需接線` | 光交圖不夠，程式端要加讀取邏輯（Claude 線負責，見 [90 工單](90_codex_art_backlog.md#程式接線清單)） |

**優先順序**

| 標記 | 意思 |
|------|------|
| P0 | 現在就看得到的畫面：提升目前版本的品質 |
| P1 | 下一波內容：新街區、服裝店、車輛、更多 NPC |
| P2 | 海外市場、機場、港口貿易、結算危機章節 |
| P3 | 更多產業、豪宅、私人飛機、控股集團 |

## 命名規則

- 所有 id 用小寫加底線（`bloom_coffee`、`tree_round_b`）。**檔名等於 id**，遊戲依路徑讀圖：
  `Art.tex("interiors/menu_board")` → `game/assets/interiors/menu_board.png`。
- 夜間燈光疊圖：`<id>_lights.png`，和本體同尺寸。
- 車輛：`<車種>_<方向>_body.png`（會被染色）加 `<車種>_<方向>_detail.png`（不染色）。
- 角色圖層：`<部位>_<款式>[_<體型>][_<分件>].png`，例如 `outfit_barista_feminine_top.png`。
- 新東西用新 id，**不要改舊檔名**。改名會讓程式找不到圖。

## 維護

- 遊戲資料（`game/data/`）或美術檔（`game/assets/`）新增 id 時，同步更新對應頁面。
- `python3 tools/wiki_check.py` 檢查每個美術檔和資料 id 都在 wiki 裡出現過。漏寫的會列出來，並回傳非 0。
