# 多公司與控股集團（Implemented，#91）

玩家可以再次到 City Hall 登記營運公司，或選擇控股公司；公司 OS 上方可切換目前操作的公司。各公司有獨立的庫存、員工、產業狀態、執照、股權、信貸評分與銀行帳目。個人住宅、世界事件、時間與已完成的城市地標保留在同一個世界。切換公司不會讓另一家公司的訂單或員工停止運作。

控股公司的 Group 分頁可將創辦人全資持有的營運公司移入集團。股權按帳面投資成本移轉，母公司列「子公司投資」，子公司股權改由母公司持有；不能移入別人的股權，也不能建立循環持股。可按帳面價值將子公司移回創辦人，沒有虛構銷售收入。關閉母公司前須先處理仍在營運的子公司，避免把玩家卡在無法處理的公司。

集團貸款須有母公司現金，資金實際流入旗下子公司；每三十天按年利率 6% 計息。子公司沒現金時列應付利息，母公司列應收利息。管理服務實際花一小時，子公司付現、母公司收現。子公司之間能按自訂單價移轉實際零售商品，賣方必須有庫存、買方必須有現金。#71 的同公司跨產業供應與工作流程繼續保留。

月結保存合併報表；對外營收不含集團內營收，內部貸款與應收利息互相沖銷，子公司投資亦沖銷。尚未對外售出的商品加價須從合併存貨與獲利扣除；已包裝但未交付的商品仍須沖銷，實際交付才釋放對應數量的加價，退回庫存時恢復一次。畫面列出資產、負債、現金、損益與沖銷金額，並以持股樹呈現集團架構。報表按目前持股範圍計算，沒有宣稱完整的會計準則財務報表。

子公司關閉只處理自己的庫存、員工、債務與投資帳面成本；其他子公司的銀行與營運狀態保留。沒有母公司擔保時，銀行損失不會向母公司追討。母公司明確提供擔保後，子公司未清償部分由母公司支付；若母公司現金不足，列應付債務並啟動其恢復流程。擔保只能代償一次。集團貸款則由貸方收回或沖銷，不會假裝銀行替集團承擔損失。

出售全資子公司使用既有 Acquisition 的獲利倍數與資產、負債資料，乘 90% 成交係數；不採用劇情收購的最低報價，避免靠反覆成立空殼公司套利。NPC 買方包括 Hale Group、Vesper Brands、Meridian Supply；價款入母公司帳戶、移除子公司投資，股權交易不列銷售營收。再次出售或創辦人提款會被阻擋，外部股東的清算款也不會變成創辦人收入。#90 未合併時維持 NPC 買方，未修改 Session A 競爭系統。

舊存檔的公司字串會移成清單第一筆，補目前操作公司與公司狀態快照；原有排程先綁定原公司。排程執行時載入所屬公司的狀態，完成後回到玩家正在看的公司。關閉公司的歷史合約仍可查，但不能使用新公司庫存交付。短 tour 以受控時間執行登記、持股移轉、第二家子公司、融資及月結，不是無介入的長年平衡模擬。

國貿隔離：貨物、報價使用量、許可狀態與出貨排程屬於原公司，切換公司不會複製或挪用。舊多公司存檔若仍共用國貿紀錄，讀回時依貨物原公司綁定資料與排程，不重新支付供應商或產生營收；關閉原公司不影響其他公司的國貿資格。

國貿危機決策也保存原貨物公司，改道與避險由原公司付費，畫面列出貨物所屬公司；切換後會回復玩家原本檢視的公司。關閉原公司會移除其待處理的國貿決策，避免阻擋或誤扣其他公司的款項。既有辦公室租約所有權檢查不變。
