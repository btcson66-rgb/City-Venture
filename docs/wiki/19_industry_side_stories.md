# 產業支線（#86）

六段支線已接到真實產業狀態。登記公司後，符合公司現金門檻或進入第二年，就能在手機「機會」接受。每段四步，進度綁定接受時的公司，不取代主線。未經營的產業在 Business Board 顯示引路人、實際工作場所與門檻，可標記到地圖。

| 資料識別 | 產業與引路人 | 實際流程 |
|---|---|---|
| `intro_manufacturing` | Lena Park／製造 | 見面、接代工單、首批瑕疵的外包或加班補救、真實交貨 |
| `intro_real_estate` | Diane Harlow／房產 | 見面、經紀執照、首次成交、第一間出租物業 |
| `intro_media` | Dr. Cole／媒體 | 見面、實際提案、在營運中的客戶案處理公關危機、結案成效 |
| `intro_hotel` | Henri Dubois／飯店 | 交接、支付承租或購買、完成團體住宿、Vera Stone 入住決策 |
| `intro_automotive` | Frank Doyle／汽車 | 拍賣入門、買入、處理真正存在的泡水車、租車車隊 |
| `intro_energy` | Ms. Okoro／能源 | 補助入門、屋頂報價、完成安裝、充電站 |

`intro_factory_quality` 只在實際代工批次有瑕疵且訂單未完成時觸發；兩個選擇各預約兩小時外包／加班產能。外包按剩餘訂單件數支付服務成本；自有工廠加班沿用技術員薪資、材料和良率。完成的工作不會為了故事重演一次失敗。

媒體、公關與旅館事件沿用現有產業效果。汽車事件須有未修復的泡水車，不會替正常車憑空加瑕疵；首車已出售而來不及處理時會略過這一步。每段九十天未完成會結束機會，不發成功獎勵；公司關閉也會清除待辦。已完成條件直接往下走，重複檢查不重發獎勵。主線繼續可玩。

成功獎勵是 Timeline 紀錄與引路人的手機聯絡對話，不直接給現金，也不改另一條 session 的社交系統。`omar_haddad` 是 Customs House 的國際貿易引薦人，使用 `omar_haddad_intro` 的實際對話與工作日排班。

每個產業第一次打開 Company OS 分頁會看到四步首單導引；已做的步驟略過，之後回來會顯示下一個步驟，可跳過。導引存在既有 tutorial 存檔內，依公司和產業區分；舊存檔延遲補上預設值。
