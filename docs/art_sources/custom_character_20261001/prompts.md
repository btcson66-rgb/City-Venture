## Production integration

Generated atlas placement was visually inspected and normalized per component rather than trusting the model's grid padding. `component_manifest.json` records the principal-alpha-subject crop. Neutral grayscale conversion enables the existing multiplicative tint system. Head/hair placements, vector masks, body shapes, garment silhouettes, pose joints and eye/brow/mouth expression geometry are explicit in the editable source. The generated original images are preserved unchanged here.
