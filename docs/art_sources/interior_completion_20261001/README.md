# Interior completion sources

Five generated source assets, exact prompts, a rejected warm mannequin revision and seven archived original material tiles are preserved here. References: docs/reference/concept_boards/H_building_interiors.webp and the existing high-resolution sofa.

tools/art/interior_completion_pack.py crops inspected bounds, trims negligible alpha, fits proportionally, packs native and exactly 4x images, repeats the seven original floor tiles without changing their existing pattern scale, and extracts the server indicator emission mask. It does not paint illustrations. manifest.json records output sizes and hashes; crops.json records reviewed source bounds. packed_preview.png is a contact sheet, not a game screenshot.

33 assets: 25 furniture/fixtures/blank identity plaques and eight floors; one additional server emission mask. 68 output PNG with import files. Original filenames and all logical sizes preserved. No game scripts, data or tests changed. Six blank identity plaques require program overlaid location text. Stock box stacks still use native art through a separate runtime path.

Status: this batch validated; whole-game quality review remains PARTIAL. Drafts for character, traffic and streets are separate and not merged into this branch.
