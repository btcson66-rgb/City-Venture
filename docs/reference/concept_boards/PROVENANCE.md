# Concept-board provenance

The repository owner confirmed on 2026-10-08 that the seven user-supplied City Venture concept boards were AI-generated. These are the project reference boards A, C, D, E, F, G and H in this directory. Project art manifests document subsequent original generated and procedural assets.

This records the supplied-material origin for the authorized repository publication. It does not add an open-source license, dedicate project assets to the public domain, or change the separate SIL OFL notices shipped with the fonts.
